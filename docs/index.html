CSV schema and time semantics

Required headers: order_id, arrival_time, pick_start, pick_end, pack_start, pack_end. Optional: picker, packer. Use ISO timestamps with offsets. Arrival means release to picking. Blank incomplete stages are allowed; completion-only stages never become active service time.
